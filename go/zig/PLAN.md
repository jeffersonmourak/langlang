# Plan — `-output-language zig`: a Zig backend for langlang

Branch `zig-parser-gen` of `jeffersonmourak/langlang`, forked at upstream tag `go/v0.0.12` (commit `1da9682`) — the exact generator that produced `circ-compiler/lib/parser/parser.go` (verified: regenerating with a binary built from this checkout is byte-identical except the header commit-hash line).

## What is being built

A second code generator beside `go/gen.go`: `go/genzig.go`, selected with `-output-language zig`, that emits **one self-contained Zig file** — a hand-written runtime (`go/zig/langlang_runtime.zig`, a line-by-line port of `go/vm.go` + `vm_stack.go` + `vm_charset.go` + `tree.go`) pasted verbatim, followed by the grammar's bytecode tables as `comptime` data, a `Rule` enum of entry addresses, and `pub const Parser = runtime.Interpreter(bytecode, Rule, &left_recursive_rules)`. Nothing else in the runtime may declare or reference a name the generated file declares at top level (`bytecode`, `Rule`, `entry_rule`, `left_recursive_rules`, `Parser`) — a pasted namespace resolves such a name to both declarations and Zig rejects the reference as ambiguous, which is also why the file has no type re-exports. The generated file compiles with Zig 0.15.1 for native targets and for `wasm32-freestanding` with no libc, takes an allocator from the caller, and reproduces the Go VM's trees, byte spans, error-recovery nodes and error messages **byte for byte**, proven by a differential harness that runs the in-process Go VM and the generated Zig parser over the same inputs and compares a canonical dump.

The front end is untouched: the grammar parser, compiler and `Encode(asm, cfg)` (`go/vm_encoder.go:7`) are shared with the Go backend, so the `code` table the Zig file carries is identical to the one inside the Go parser and tree parity reduces to VM-semantics parity. The **full instruction set** is implemented — all 33 opcodes including left recursion (`call_lr`/`return_lr`/`cap_return_lr`), the fail path, recovery labels, expected-hint tracking and `mkErr` text — so a grammar that grows into any langlang feature regenerates without runtime work.

Consumer contract (executed later in `circ-compiler`'s libcirc initiative, proven here first): circ vendors the output as `lib/parser/parser.zig`, deletes `lib/parser/{parser.go,shim/,parser.a,parser.h}`, `lib/syntax/CParser.zig` and every `linkParserArchive`/Go build step, and `lib/syntax/translate.zig` swaps its six cgo accessors for the Zig `Tree` API. The 27 `expected-ast` goldens must stay byte-identical.

Definition of done: `go test ./...` green on the fork's Go-only CI (Zig-dependent tests skip) and green with `LANGLANG_REQUIRE_ZIG=1` in a Zig 0.15.1 job; the differential harness reports zero mismatches over the langlang VM test table (4 configurations), every `go/tests/*.peg` grammar including `arithmetic_leftrec`, and circ's `proto-circ.peg` over every `tests/fixtures/circuits/*.circ`; the generated circ parser builds for `wasm32-freestanding`; `go/zig/CIRC.md` carries the exact cut-over checklist.

The `c-output` branch upstream (`go/genc.go` + `go/c/`) is the structural precedent for a second backend — **template only**: its C VM predates v0.0.12, lacks `char32`/`range32`/the three LR opcodes, and calls the old single-argument `Encode(asm)`. Port from `go/vm.go` on this branch, never from `go/c/vm.c`.

## Generated file shape

```zig
// Code generated by langlang (<hash> commit hash), DO NOT EDIT.
// Source File: lib/grammar/proto-circ.peg
// Runtime: langlang_runtime.zig abi=1 sha256=<hex> (Zig 0.15.1, native + wasm32-freestanding, no libc)
const std = @import("std");                      // the only @import in the file

// ---- BEGIN langlang runtime ----
pub const runtime = struct {
    <go/zig/langlang_runtime.zig with its single top-level `const std = @import("std");` removed, indented>
};
// ---- END langlang runtime ----

// No re-exports: `pub const Tree = runtime.Tree;` at top level would make every
// `Tree` inside the pasted runtime an ambiguous reference, so consumers spell
// `parser.runtime.Tree`, `parser.runtime.NodeType`, ...

pub const bytecode = runtime.Bytecode{
    .abi = 1,                                     // copied from the runtime source at generation time
    .code = &[_]u8{ 11, 5, 0, 0, 0, 15, 6, 0, ... },   // Encode() output verbatim, 24 per line
    .strs = &[_][]const u8{ "", "trailing", "busname", ... },   // strs[0] == "" sentinel; every byte escaped as \xNN when needed
    .sets = &[_]runtime.Charset{ .{ .bits = .{ ...32 u8... } }, ... },
    .sexp = &[_][]const runtime.Expected{ &.{ .{ .a = 0x30, .b = 0x39 } }, &.{}, ... },   // integers, never rune literals
    .rxps = &[_]i32{ -1, 1344, 1352, 1360, 1368, 1376, -1, ... },   // len == strs.len; replaces both the rxps map and rxbs
    .srcm = null,                                 // or a SourceMap when generated with --grammar-source-map
};
pub const Rule = enum(u16) { Program = 5, AnonDecl = 734, ..., busclose = 1376 };   // @"..." only for keywords / non-identifiers (zig fmt strips the rest)
pub const entry_rule: Rule = .Program;
pub const left_recursive_rules = [_]Rule{};       // targets of any call_lr in the program
pub const Parser = runtime.Interpreter(bytecode, Rule, &left_recursive_rules);
test "langlang tables" { try runtime.verifyTables(bytecode); }
```

With `-zig-runtime-import=<name>` the pasted block becomes `pub const runtime = @import("<name>");` and `-zig-emit-runtime <path>` writes the runtime file — for packages hosting several parsers. Not the mode circ uses.

## Runtime public API (inside `runtime`; reached as `parser.runtime.*`)

```zig
pub const abi_version: u32 = 1;
pub const langlang_version = "go/v0.0.12";
pub const NodeId = u32;
pub const NodeType = enum(u8) { string = 0, sequence = 1, node = 2, err = 3 };   // api.go:32-41; circ's translate.zig:11-14 hard-codes these
pub const Charset = struct { bits: [32]u8, pub inline fn has(self: Charset, b: u8) bool };
pub const Expected = struct { a: u21, b: u21 = 0 };
pub const Bytecode = struct { abi: u32, code: []const u8, strs: []const []const u8, sets: []const Charset,
                              sexp: []const []const Expected, rxps: []const i32, srcm: ?*const SourceMap = null };
pub const Node = struct { typ: NodeType, start: u32, end: u32, name_id: i32, child_id: i32, message_id: i32 };  // tree.go:33-40, -1 = none
pub const Range = struct { start: usize, end: usize };                            // byte cursors only
pub const LabelMessage = struct { label: []const u8, message: []const u8 };
pub const Tree = struct {
    pub fn root(t: *const Tree) ?NodeId;            // null when the VM never set a root (empty input)
    pub fn typ(t: *const Tree, id: NodeId) NodeType;
    pub fn name(t: *const Tree, id: NodeId) []const u8;
    pub fn message(t: *const Tree, id: NodeId) []const u8;   // err nodes: bound label message, else the label name
    pub fn range(t: *const Tree, id: NodeId) Range;
    pub fn child(t: *const Tree, id: NodeId) ?NodeId;
    pub fn childrenLen(t: *const Tree, id: NodeId) usize;    // 1 for node/err with a child, N for sequence, 0 for string
    pub fn childAt(t: *const Tree, id: NodeId, i: usize) ?NodeId;
    pub fn sequenceChildren(t: *const Tree, id: NodeId) []const NodeId;
    pub fn slice(t: *const Tree, id: NodeId) []const u8;     // input[start..end]
    pub fn dump(t: *const Tree, w: *std.Io.Writer) std.Io.Writer.Error!void;   // canonical differential format
    pub fn copy(t: *const Tree, gpa: std.mem.Allocator) std.mem.Allocator.Error!Tree;
    pub fn deinit(t: *Tree, gpa: std.mem.Allocator) void;
};
pub const ParseError = struct {
    label_id: u32, start: u32, end: u32 /* = ffp */, ffp_pc: u32, unexpected: ?u21 /* null == EOF */, expected: []const Expected,
    pub fn label(e: ParseError, bc: *const Bytecode) []const u8;
    pub fn writeMessage(e: ParseError, w: *std.Io.Writer, bc: *const Bytecode, messages: []const ?[]const u8) std.Io.Writer.Error!void;  // mkErr text
    pub fn messageAlloc(e: ParseError, gpa: std.mem.Allocator, bc: *const Bytecode, messages: []const ?[]const u8) std.mem.Allocator.Error![]u8;
};
pub const MatchResult = struct { tree: ?*const Tree, cursor: u32, err: ?ParseError };
pub const Error = error{ ParseFailed, OutOfMemory, InvalidBytecode };
pub fn verifyTables(comptime bc: Bytecode) !void;
pub fn Interpreter(comptime bc: Bytecode, comptime RuleT: type, comptime lr_rules: []const RuleT) type { return struct {
    pub fn init(gpa: std.mem.Allocator) Self;                // pre-sizes like NewVirtualMachine (vm.go:235-254)
    pub fn deinit(self: *Self) void;
    pub fn setShowFails(self: *Self, v: bool) void;          // default false (as generated Go parsers and circ)
    pub fn setLabelMessages(self: *Self, msgs: []const LabelMessage) void;   // by-name into a comptime-sized table; replaces CompileErrorLabels' strs mutation
    pub fn match(self: *Self, input: []const u8) std.mem.Allocator.Error!MatchResult;              // == vm.Match: runs the `call <first>; halt` prologue from pc 0
    pub fn matchRule(self: *Self, input: []const u8, rule: RuleT) std.mem.Allocator.Error!MatchResult;   // == MatchRule; LR-aware for rules in lr_rules
    pub fn parse(self: *Self, input: []const u8) Error!*const Tree;       // match(); on failure stores last_error, returns error.ParseFailed
    pub fn parseRule(self: *Self, input: []const u8, rule: RuleT) Error!*const Tree;
    pub fn tree(self: *const Self) *const Tree;                           // owned by the Parser, reset on the next match (api.go borrowed contract)
    last_error: ParseError, messages: [bc.strs.len]?[]const u8,
}; }
```

## Runtime design

- **Two layers.** `Machine` is the VM over *runtime* tables (`bc: *const Bytecode`, label messages in an allocated `[]?[]const u8`); `Interpreter(comptime bc, RuleT, lr_rules)` is the thin comptime wrapper generated parsers use (`Parser = runtime.Interpreter(...)`, `init(gpa)`, `match`, `matchRule`, `parse`, `parseRule`, `setLabelMessages`, `tree`, `lastError`). The split lets a dynamic host — the differential harness's `vmdriver`, or a future REPL — drive tables it loads at run time without generating and compiling a parser per grammar; `Machine.matchAddress(input, rule_address, left_recursive)` is the single entry point both share.
- **Memory:** allocator-explicit, no globals, the runtime never names an allocator (`std.heap.wasm_allocator` is a compile error on native). Growable state is Zig 0.15.1 unmanaged `std.ArrayList(T) = .empty` (tree nodes/children/child_ranges; stack frames/node_arena/top_nodes/lr_data); the LR memo is `std.AutoHashMapUnmanaged(LrMemoKey{addr, cursor}, LrMemoEntry)` with a per-entry capture list; `expected` is a fixed `[20]Expected` + count. `u32` for cursor/pc/start/end (`input.len <= maxInt(u32)` is a precondition).
- **Tree:** Go's struct-of-arrays layout verbatim (`tree.go:33-50`); builders `addString/addSequence/addNode/addNamedString/addError/addErrorWithChild` are 1:1 ports of `tree.go:154-248` — including `addNamedString` appending a String *then* a Node — because node-id order is asserted by the canonical dump. `root_id` is set only where Go calls `SetRoot` (`vm.go:318-322`, `:601-605`). Backtracking discards via arena truncation only; orphan nodes remain, as in Go.
- **Stack:** one 32-byte `Frame` for all four kinds (`vm_stack.go:14-45`); `top()` returns a pointer into `frames.items` that is valid only until the next `frames.append` — audited holders (`opPartialCommit`, `opCapPartialCommit`, `doReturnLR`, `doCapReturnLR`) never push while holding it; a debug assertion guards this.
- **VM loop:** `switch (code[pc])` over the 33 opcodes with the fail path as a labeled inner loop, porting `vm.go:572-607` exactly. Operands read with `std.mem.readInt(u16/u32, ..., .little)`; sizes per `vm.go:191-233` (`call` and `call_lr` are 4 bytes — the trailing precedence byte is `0` on plain calls). Terminals decode runes with a hand-rolled decoder reproducing Go's `utf8.DecodeRune` contract (`vm.go:1004-1009`: invalid/truncated ⇒ U+FFFD with size 1); `set`/`span` test raw bytes (charsets only ever hold code points < 0x80).
- **newNode** (`vm.go:797-862`) ported line by line: 0 children ⇒ String if width > 0, else nothing unless the capture is a recovery label; 1 child ⇒ that child; ≥ 2 ⇒ Sequence; recovery labels wrap in Error with `message_id` = bound message else the label id; `cap_id == 0` captures bare.
- **Left recursion** (`vm.go:617-765`) 1:1 in v1, including two multiple-assignment quirks the differential harness caught: Go's `pc, cursor, failed = vm.doCallLR(...)` and `pc, cursor, gotoCode = vm.doFailLR(...)` write `(0, 0)` on their non-resuming paths, so a `call_lr` that fails on the memo records ffp 0 when nothing had failed yet, and an LR frame popped during the final unwind leaves an exhausted parse reporting cursor 0 (`Unexpected 'l'` at 0 rather than the real failure position). Both are copied. `matchAddress(addr, left_recursive = true)` enters through `enterLR` (precedence 1, return address 4) — the one deliberate difference from Go's `MatchRule`, which crashes there — and `TestGenZigLeftRecursiveEntry` proves it against Go's `Match` on `tests/arithmetic_leftrec/expr_only.peg`, whose first rule is the LR one: memo entries created on first `call_lr` and deleted on finalize and on every `doFailLR` path, captures snapshotted per grow. The LIFO folding of the memo into `lr_data` is a post-parity optimisation, behind a debug assertion that every memo hit maps to a live `lr_call` frame.
- **Errors:** `ParseError` built structurally at the failure site; `writeMessage` reproduces `mkErr` (`vm.go:895-953`) on demand; label messages come from the consumer through `setLabelMessages` into a `[strs.len]?[]const u8` table (comptime tables cannot be appended to, unlike `CompileErrorLabels`, `vm.go:41-60`).
- **Not ported:** `pos.go` rune-based Location/Span/CursorU16, `Pretty`/`Highlight` with `strconv.Quote` escaping, `Text()` concatenation, `Visit`. The canonical byte-cursor dump is the oracle.

## Generator design

`go/genzig.go`: `GenZigEval(asm *Program, cfg *Config, opt GenZigOptions) (string, error)` with the same shape as `GenGoEval` (`gen.go:33`), calling the same `Encode(asm, cfg)`. Pipeline: header (commit hash via `getCommitHash`, `abi` read by regexp `^pub const abi_version: u32 = (\d+);$` from the embedded runtime, runtime sha256) → paste the runtime with its single `const std = @import("std");` line removed and 4-space indented (or the `@import` line in import mode) → tables mirroring `gen.go:85-231` (`code` 24/line; `strs` through a new `zigQuote` that escapes every non-printable byte as `\xNN`; `sets` as `[32]u8`; `sexp` as integer pairs; `rxps` as a `[strs.len]i32` with `-1` default, subsuming `rxbs`; `srcm` when present) → `Rule` enum from the same address-map walk as `gen.go:255-267`, fields `@"..."`-quoted only when they are Zig keywords or not plain identifiers (`zig fmt` strips unnecessary quotes), `entry_rule` = first definition, `left_recursive_rules` = targets of any `ICallLR` → `Parser` alias → emitted `verifyTables` test. **No `text/template` pass** (`gen.go:322` would choke on `{{` in Zig source) and **no formatter at generation time**: the emitter is written `zig fmt`-clean (multi-row array literals are column-aligned the way `zig fmt` lays them out; one-element lists carry no inner spaces) and `zig fmt --check` runs as a test, so generating never needs a Zig toolchain. Errors instead of the Go encoder's silent `uint16(label)` truncation when `code` or `strs` exceed 65535. Reuses `outputWriter` (`gen.go:402-447`).

CLI (`go/cmd/langlang/main.go`): `case "zig":` beside `case "go":` (`:222-235`), flags `-zig-runtime-import` (default `""`) and `-zig-emit-runtime <path>`; grammar flags (`-disable-capture-spaces`, …) flow through `cfg` unchanged.

Canonical dump (both sides, byte-identical): `cursor=<n>`; then `root=<id>` followed by one pre-order line per node — `<2·depth spaces>#<id> <string|sequence|node|err> <name or -> <start> <end>` (err lines append ` msg=<message>`) — or `noroot`; on failure an `error label=<label or -> start=<s> end=<e> tree=<yes|no> msg=<mkErr text>` line precedes the tree. Go side: `go/tree_canonical.go` `CanonicalDump(t Tree, cursor int, err error) string`, using a new **private** `hasRoot` flag on `tree` (set in `SetRoot`, cleared in `reset`; public `Root()` unchanged) so Go prints `noroot` exactly when the VM never set a root — the only place Zig's `?NodeId` and Go's `root < len(nodes)` heuristic (`tree.go:62`) could disagree. Zig side: `Tree.dump` + `go/zig/testdriver.zig`.

Differential harness (`go/genzig_diff_test.go`): `TestGenZigDifferential/vm` serialises each VM-table case's `Bytecode` into a small blob (`zigTableBlob`: magic `LLZT`, abi, code, strs, sets, sexp, rxps — written *before* `CompileErrorLabels`, which appends to `strs`) and replays it through one `vmdriver` binary in all four configurations; `/grammars` generates `parser.zig` per test grammar, builds `testdriver` against it, and replays `tests/<grammar>/inputs/*` (plus `grammars/*.peg` for the langlang grammar and `input_30kb.json` for json). `--rule-address <n> [--rule-lr]` drives `matchAddress` for the LR-entry test.

Tests: `go/zig/langlang_runtime_test.zig` (charset, UTF-8 decoder edge cases, tree builders incl. id order and `root()==null`, stack adoption/truncation, VM on hand-assembled byte arrays copied from `langlang -grammar-asm`); `go/genzig_test.go` — `TestGenZigEmit` (golden of the emitted tail for `go/tests/recovery/recovery.peg`, **no Zig needed**; `zigQuote`, abi regexp and the > 0xFFFF guard) and `TestGenZigCompiles` (for `go/tests/{basic,charsets,recovery,arithmetic,arithmetic_leftrec,import}` + `grammars/{json,langlang}.peg` with the flags of their `//go:generate` lines: generate into a temp dir, `zig test parser.zig`, `zig build-obj -target wasm32-freestanding -O ReleaseSmall`, `zig fmt --check`; both modes); `go/genzig_diff_test.go` — `TestGenZigDifferential` over the hoisted `vmTests` table × 4 configs, the `go/tests` grammars with inputs seeded from their test literals, a corpus mode driven by `LANGLANG_DIFF_GRAMMAR`/`LANGLANG_DIFF_FLAGS`/`LANGLANG_DIFF_CORPUS`/`LANGLANG_DIFF_LABELS`, and `TestGenZigTablesMatchVendoredGo` (`CIRC_PARSER_GO=<path>`: the `code` literal parsed out of circ's `parser.go` must equal the emitted table). Skip logic everywhere: `exec.LookPath("zig")` fails ⇒ `t.Skip`, unless `LANGLANG_REQUIRE_ZIG=1` ⇒ `t.Fatal`. Generated `go/tests/*/*.zig` outputs are gitignored like the `.go` ones.

CI: `.github/workflows/go.yml` keeps its Go 1.21–1.24 matrix (Zig tests skip). ## Constraints

- Bytecode ABI is frozen: opcode order `vm.go:118-153`, sizes `vm.go:191-233`, little-endian u16/u32 operands, absolute u16 jump targets (the Zig generator errors instead of truncating), u8 precedence, `strs[0] == ""`.
- Same `Encode(asm, cfg)` output for every backend; the Zig generator emits `code` verbatim and never re-derives compiler decisions (`cap_*_offset` usage, inlining, LR call sites, recovery mapping).
- Generated Zig compiles on 0.15.1 for native and wasm32-freestanding with no libc: only `std.mem`, unmanaged `std.ArrayList`, `std.AutoHashMapUnmanaged`, `std.Io.Writer`; never `std.fs`/`std.process`/`std.debug`/`@cImport`/`std.heap.*`; no `@panic` on data-dependent paths (unknown opcode ⇒ `error.InvalidBytecode`).
- One file by default with `std` as its only import; one runtime file with one strip rule; no `text/template`; no formatter at emit time.
- Tree-shape parity: `NodeType` 0..3, struct-of-arrays layout, builder order, `newNode` rules, root only where Go sets it, byte-cursor spans only.
- Go quirks are **copied, not fixed**: `vm.predicate` restored from the popped backtrack frame (`vm.go:586`), `fail_twice` pops without truncation (`:426-428`), `doFailLR`'s `lr.result > 0` (`:752`), unread `bound`, byte-wise `set`/`span`, no expected hint at EOF (`:335-337`), `(U+FFFD, 1)` decode fallback. The one deliberate improvement is the LR-aware `matchRule` entry.
- Fork CI stays green without Zig and fails with Zig present when parity breaks.
- circ's contract: byte cursors; `root() == null` on empty input; `childrenLen == 1` for node/err with a child; names compared by bytes; `ParseFailure` from `{start, end, message}`.

## Traps

- `upstream/c-output` is a structural template only (no LR/`char32`/`range32`, old `Encode(asm)`).
- `gen.go`'s `text/template` pass breaks on `{{` in Zig; `sexp` is emitted with `strconv.QuoteRune` in Go (rune-literal syntax) — emit integers; `escapeLiteral` (`tree_printer.go:57-67`) handles only five escapes — use a full byte quoter.
- `opCall` is 4 bytes with a trailing precedence byte that is always `0`; forgetting it desyncs `pc`.
- `MatchRule(addr > 0)` pushes a plain Call frame; entering a left-recursive rule that way ends in `return_lr` reading `lrData[lrIdx-1]` with `lrIdx == 0` — `match()` runs from pc 0, `matchRule` on LR rules pushes an LRCall frame.
- Go `Root()`'s `root < len(nodes)` heuristic can return orphan node 0 — Zig's `?NodeId` deviates only there; the Go dumper's private `hasRoot` flag compares the intended semantics.
- Empty input: `cap_end` with 0 nodes and 0 width emits nothing and `SetRoot` is never called ⇒ root must be null (circ pins `error.ParsingFailed`).
- `CompileErrorLabels` appends to shared `strs`/`smap`; comptime tables cannot grow — resolve names at `setLabelMessages` time.
- `decodeRune` must return `(0xFFFD, 1)` on invalid UTF-8; `std.unicode.utf8Decode` is deprecated in 0.15.1 and errors differently — hand-roll and unit-test.
- `std.heap.wasm_allocator` referenced from a native compile is a hard error; the runtime must never name an allocator.
- `stack.top()` returns a pointer into `frames.items`; any `frames.append` while holding it is UB.
- A second top-level `std` alias in the runtime yields "ambiguous reference" after pasting (verified); Zig rejects `@import` across module roots (verified) — circ needs a `parser` module.
- `showFails` is never enabled by generated Go parsers or circ; hint ordering only matters for `recovery_test.go:150-197`.
- circ's two label-message tables disagree for `trailing`; the corpus run must use the table circ keeps.
- `vmTests` is function-local (`vm_test.go:60`); hoisting it is required for the harness.
- The header commit hash is `unknown` under `go run`; the runtime sha256 line is the reliable skew signal.
- `.github/workflows/go.yml` has no Zig; an unguarded Zig-requiring test breaks the 1.21–1.24 matrix; generated `.zig` outputs must be gitignored like the `.go` ones.
